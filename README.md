Live Link For the Website : https://prashant-hada.github.io/Ochi-design-Site/

## Setup Instructions

1.  **Clone the repository:**

    `git clone <repository-url>  `
    
    `cd <project-folder>` 
    
2.  **Install dependencies:**

    `npm install` 
    
3.  **Start the development server**

    `npm run dev`
